# 2FTA - Что было добавлено и их функция

**Author:** Madiyar

## Краткий итог

Я взял исходный backend-проект и доработал его до полноценного full-stack fitness tracker с Angular frontend, JWT-аутентификацией, видео для упражнений, улучшенной статистикой, историей сессий, загрузкой аватарки и более строгой валидацией.

---

## Что я добавил и их функция

| Что добавлено | Функция / назначение |
|---|---|
| JWT authentication | Перевод авторизации с обычного token auth на JWT, чтобы соответствовать требованиям проекта и работать через `access` + `refresh` токены |
| JWT login / register / logout endpoints | Дают возможность регистрироваться, входить и выходить через новый auth flow |
| Angular HTTP interceptor | Автоматически отправляет `Bearer` токен в защищенные запросы |
| `image_url` в `Exercise` | Позволяет хранить и отображать картинку упражнения |
| `video_url` в `Exercise` | Позволяет хранить YouTube/video ссылку для техники упражнения |
| `exercise_type` в `Exercise` | Позволяет отображать тип упражнения (`compound`, `isolation`, etc.) |
| `base_coefficient` в `Exercise` | Дополнительное поле для конфигурации/отображения коэффициента упражнения |
| `is_active` в `Exercise` | Позволяет скрывать или отключать упражнения без удаления из БД |
| Новая muscle category `yoga` | Расширяет список категорий упражнений |
| `batch_id` в `ExerciseSet` | Позволяет одному UI-элементу с несколькими `sets` сохраняться как группа backend set-ов |
| `created_at` в `ExerciseSet` | Дает временную метку для статистики, истории и сортировки |
| Увеличенная точность `weight_kg` | Позволяет хранить вес точнее и безопаснее для статистики |
| Seed-команда `seed_fitness_data` | Быстро заполняет БД готовыми упражнениями, YouTube-ссылками и описаниями для демо |
| `GET /api/exercises/muscles/` | Отдает список категорий мышц для фронтенда |
| `POST /api/sessions/start/` | Создает активную тренировочную сессию |
| `GET /api/sessions/current/` | Возвращает текущую активную сессию пользователя |
| `GET/POST /api/sessions/exercise-items/` | Frontend-friendly слой для логирования упражнений как одного элемента, а не ручной работы с отдельными set-ами |
| `DELETE /api/sessions/exercise-items/<id>/` | Удаляет целую группу set-ов, созданных одним действием пользователя |
| `GET /api/sessions/history/` | Возвращает историю тренировок с фильтрами, пагинацией, summary и деталями по каждой сессии |
| `GET /api/stats/weekly/` | Отдает weekly stats для графиков фронтенда |
| Расширенный `GET /api/stats/` | Отдает больше аналитики: объем, средний вес, streaks, best session, top exercises, time series |
| `GET /api/stats/dashboard/` | Удобный alias endpoint для фронтенда под расширенную статистику |
| Более строгая backend validation | Защищает от некорректных данных: слишком длинные поля, невалидный вес, слишком много reps/sets, неправильный avatar |
| Валидация avatar type/size | Проверяет, что пользователь загружает изображение, а не произвольный файл, и что размер файла не слишком большой |
| `transaction.atomic()` при batch logging | Делает сохранение группы set-ов безопасным: либо создаются все, либо ни один |
| Перенос Angular frontend в `2FTA` | Позволил работать с отдельной копией фронта, не ломая старый проект |
| Новый frontend auth flow | Подстроил фронтенд под JWT backend |
| Login page в стиле 2FTA | Сделал кастомный экран логина/регистрации под референс |
| Sidebar + profile bar layout | Сделал основную оболочку приложения |
| Страница `Exercises` | Позволяет смотреть упражнения по категориям и проигрывать видео техники |
| YouTube player на `Exercises` | Показывает технику упражнения прямо в приложении |
| Страница `Session` | Позволяет начать тренировку, выбрать упражнение и залогировать его |
| Popup логирования упражнения | Ускоряет ввод `weight / reps / sets / notes` |
| Страница `Stats` | Показывает графики и общую статистику прогресса |
| Avatar display + upload на фронтенде | Позволяет отображать аватар и менять его без админки |
| Упрощение muscle participation UI | Убрал лишние проценты из интерфейса, чтобы UI был чище |
| `full_db.json` | Полный экспорт БД в формате Django fixture |
| `2FTA_db_bundle.zip` | Готовый архив для передачи БД и медиа другому человеку |
| `PROJECT_HANDOFF_Madiyar.md` | Полный handoff-документ по проекту |

## Что было сохранено из исходного проекта

Я не ломал основную тренировочную логику, а сохранил ее как ядро:

| Что уже было в исходном проекте | Что с этим сделано |
|---|---|
| `User` | Сохранен и расширен через frontend profile/avatar flow |
| `Session` | Сохранена как основная модель тренировки |
| `ExerciseSet` | Сохранена как основная модель логирования сета |
| `LastSet` | Сохранена для хранения последнего результата по упражнению |
| Point calculator | Сохранен и встроен в новый frontend flow |
| Пересчет `points_sum` у сессии | Сохранен без поломки |
